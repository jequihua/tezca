# Try Tezca with synthetic inputs

Install in a fresh environment and follow the [quickstart](../quickstart.md).
Keep observed/supplied outputs and expected identities separate; compare statuses,
support, references and literal controls as well as values. Run [portable tests](../contributing.md).
For optional objects/models use the separately compatible versions documented in
[EcoFill](../ecofill.md) and [regimes](../regimes.md).

Before real-data use, establish access, units, QC, clocks, lineage and scientific
tolerances. Synthetic examples do not establish ecological validity or historical
equivalence. Report reproducible behavior via the [bug guide](bug_report.md).
