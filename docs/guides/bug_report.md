# Report a reproducible issue

Use the [public issue tracker](https://github.com/jequihua/tezca/issues).
Provide a minimal synthetic example with expected and observed behavior:

```text
Public Git commit (git rev-parse HEAD), or wheel SHA-256:
Tezca version, Python version, OS/architecture:
NumPy/pandas/SciPy and relevant optional dependency versions:
Exact installation route and command:
Input shape, units, cadence/timezone, observation and replacement masks:
Requested method/settings, support and frozen reference selection:
Expected and observed value/status/reason:
Result bundle/source/reference identities, if applicable:
Traceback with private paths/values removed:
```

Keep expected identities separately. Never include credentials, private
observations or confidential site metadata. Preserve a failed output rather
than overwriting it; reproduce with a new destination. A checksum does not
establish scientific validity. See [troubleshooting](troubleshooting.md).
